这些记忆存在哪、从哪来（点开）
  • 正本：中心服务器，目录 /srv/agent-memory/repo/entries/，一条一个 markdown 文件，git 记着每次改动。
  • 备份：设备端的 backup 目标每天拉一份完整仓库（git bundle，含全部历史）；也可以在别的机器上定时 git clone --mirror。
  • 每台机器的离线副本：~/.agent-memory/snapshot.json，中心连不上时智能体查这个。
  • 给你看的：本页、大屏；装了 vault 目标的机器上用 Obsidian 打开 ~/Documents/共享记忆。
  • 来源方式：工具自己记的 = Claude/Hermes/OpenClaw/WorkBuddy 自带的记忆文件原样同步；会话抽取 = 从 Codex 会话里由模型抽出（候选 3 天不审自动生效）；旧卡片拆分 = 11-13 从旧知识库大卡拆的；智能体主动写 = 调 memory_remember 写的。
  • 原始的记忆文件仍在各自机器上（如 Mac 的 ~/.claude/projects/*/memory/）；改那里，这边跟着变。
